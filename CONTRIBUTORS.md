# Contributors

This file documents all contributions to this project as required by the Lama Open Ecosystem License (LOEL v1.0).

## How to add your contribution

- Option A (Recommended):
  - Add a new file in the /Contributors/ directory named `mychanges_<yourusername>.md` with:
    - Your real name
    - Description of your changes
    - Date(s) of contribution

- Option B (Alternative):
  - Add your entry below in this CONTRIBUTORS.md file with:
    - Your real name
    - Description of your changes
    - Date(s) of contribution
